# APP2 MAP R3 — Hero Area 与地图碰撞

日期：2026-09-15。实施依据：用户要求按 CURRENT_V3 审查规划并实施。基线：5091521。

## 范围

只做地图分层、1024×1024 样板区、连续地面、简化障碍、玩家滑动碰撞、敌人简单绕障、地图验证和视觉证据。已有战斗、XP、升级保留且不扩展。世界 4096×4096、逻辑 MapTile 32×32、既有 Graphics API 保持。样板区范围 [1536,2560)×[1536,2560)，不复制到全世界；外部只保留连续基础地面。

## 实施顺序与设计

1. 环境独立模块：区域、结构、显式碰撞 AABB、道具、标识、环境光。保留逻辑网格存储，256 像素块服务地面绘制与剔除；本轮少量碰撞 AABB 直接遍历。
2. 中央测试大厅保持开阔；维修位于西北、仓储西南、动力实验区东北。每区只使用相应的少数道具族，中央保留一组测试设备。
3. 大结构用明确矩形表示占地；玩家脚底中心用半径 8 的方形碰撞体，敌人采用同一空间和按类型设置的半径。轴向分步解算实现滑动并防高速穿透。地图碰撞不处理子弹、地面贴花、光和小型地面细节。
4. 敌人先尝试追击方向；遇阻时沿障碍切线移动并选择短边方向，不实现完整寻路系统。出生位置必须可通行。
5. 新地面材料从不可变源图的无边框内部提取，以 256 像素块绘制；长接缝、功能标识与警戒线单独布置，不显示32格边界，不再使用周期设备岛。
6. 测试几何碰撞、滑动、防穿透、敌人进出障碍边缘、出生合法性、样板区连通性与可通行比例；保留旧有效测试与 GPU 算术。
7. 提交三幅邻接地图视图、无角色总览、实渲染滚动序列及准确回归日志。

## 验收状态规则

自动测试只能确认几何、确定性和后端一致性。三屏不重复、背景可读性、设施整体感必须人工审阅。主要战斗区域至少70%可通行；不以小物体数量替代障碍组统计。每组主要设备的碰撞范围在总览中可检查。

本轮最终状态最多为“实现和自动验证完成，待用户视觉审阅”。不把原56项自动PASS作为审查授权，不自动关闭V3地图关口。用户确认地图后再讨论后续玩法。

# Golden Tile Binary Fixtures

Checked deterministic Tile fixtures generated by `golden_cli generate-tile-fixtures`.

Each fixture directory may contain:
- `command.bin` — TILE_FRAME 64B LE
- `descriptors.bin` — Draw Descriptor Array
- `tile_headers.bin` — Tile Header Array
- `workrefs.bin` — WorkRef array
- `initial_fb.raw` / `golden_fb.raw`
- `manifest.json`

Expected `golden_fb.raw` is produced by Immediate Golden, not Tile.

Normal build/test must not rewrite these files.
